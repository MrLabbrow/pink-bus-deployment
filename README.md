# 🚌 BRTC Pink Bus Deployment

Deploy the official Bangladesh BRTC Pink Bus directly to your terminal!

## Features
- **Dynamic Terminal Animation:** The bus flawlessly drives across your screen with spinning wheels and exits through a toll gate.
- **Responsive Sizing:** Automatically detects your exact terminal dimensions so the departure sequence works perfectly on any screen size.
- **Interactive Sequence:** Simulates a realistic system checklist and progress bar before prompting you to start the engine!

## Run Directly

Execute the following command to deploy the bus instantly (no cloning required!):

```bash
bash <(curl -sL https://raw.githubusercontent.com/MrLabbrow/pink-bus-deployment/main/launch.sh)
```
